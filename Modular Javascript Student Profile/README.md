1. What is the difference between a function parameter and a function argument?

• Answer: A parameter is a named variable listed inside the parentheses of a function definition that acts as a placeholder for incoming data. An argument is the actual value or expression passed into the function when it is called or invoked.

2. How does the this keyword behave inside an object method when referencing properties of the same object?

• Answer: When used inside a regular object method, the this keyword refers to the object that owns or invokes the method. This allows the method to access and modify other properties and methods belonging to that same object (e.g., this.propertyName). (Note: Arrow functions do not bind their own this and instead inherit it from the surrounding scope).

3. Why is modularizing code into smaller functions and separate files useful in JavaScript development?

• Answer: Modularizing code improves readability, maintainability, and reusability by breaking complex logic into smaller, single-purpose units. It also makes debugging and testing easier while allowing multiple developers to work on different parts of a codebase simultaneously without conflicts.

4. Why is it important to run git pull or git fetch before creating new commits and pushing changes to a remote repository?

• Answer: Running git pull or git fetch ensures your local repository is up to date with the latest changes made by collaborators on the remote branch. Syncing first helps prevent push rejections and allows you to resolve potential merge conflicts locally before sharing your new commits.
